==============USER MANUAL==============

----------------GENERAL----------------
Use numbers to choose options, then follow the on-screen prompts.
Type 0 at any non-options input to cancel the operation

-------------SIGN UP/LOGIN-------------
Sign up,
Use a username of at least five characters that hasn't been already created and use a password with the on-screen instructions
	
Login,
Enter credentials of a valid created account

View reminders,
Use this option to get the master admin account (this would not be in a public release, only for testing purposes)

Exit,
Use this option to exit the program

-----------------ADMIN-----------------
View and edit inventory,
Add item: follow the on-screen prompts to add an item. Items that already exist inside the chosen inventory cannot be added again

Edit item: pick an item using its ID, then follow the on-screen prompts to edit the chosen item. Items cannot be renamed to an item that already exists inside the chosen inventory

Delete item: pick an item using its ID, then follow the on-screen prompts to delete the chosen item

---------------------------------------
View and edit employees,
Add employee: follow the on-screen prompts to add an employee. Employees that already exist cannot be added again

Edit employee: pick an employee using their ID, then follow the on-screen prompts to edit the chosen employee. Employees cannot be renamed to an employee that already exists

Delete employee: pick an employee using their ID, then follow the on-screen prompts to delete the chosen employee

---------------------------------------
View and edit roster,
Assign hours to employee: pick an employee by their ID, choose a day to edit, choose an option, then follow the on-screen prompts to assign hours

Assign hours to employee for all days: pick an employee by their ID, then follow the on screen prompts to assign hours for the chosen employee's roster

Clear employee's schedule: pick an employee by their ID, then follow the on-screen prompts to clear a chosen employee's roster

Clear roster: follow the on-screen prompts to clear the entire roster

---------------------------------------
View and edit accounts,
Edit account: pick an account by its ID, then follow the on-screen prompts to edit the chosen account

Delete account: pick an account by its ID, then follow the on-screen prompts to delete the chosen account

---------------------------------------
View purchase history,
Clear recent purchases: follow the on-screen prompts to clear all recent purchases

---------------------------------------
"Low stock only" mode,
When viewing inventories with this on, only items with 5 or less stock will display on the console

---------------------------------------
Logout,
Use this option to logout of the current account

---------------------------------------
Exit,
Use this option to exit the program


-----------------USER------------------
View inventory,
Pick a store to view its inventory

---------------------------------------
Order product,
Pick a store, then follow the on-screen prompts to order a product from the chosen store

---------------------------------------
Edit account details,
Edit username: enter a new username that doesn't already exist and is at least five characters

Edit password: enter a new password following the on-screen instructions

---------------------------------------
Logout,
Use this option to logout of the current account

---------------------------------------
Exit,
Use this option to exit the program
